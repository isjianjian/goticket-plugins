# 提一个设计需求

先按 `canvas` 技能确认登录和空间，再按下面的步骤做。

## 1. 确定项目

- 用户给了项目名：`canvas_project` 的 `list` 找到它；有多个同名或相近的，列出来让用户选。
- 用户给了 projectId：用 `get_by_pid`。
- 都没给：列出最近的几个项目让用户选，不要自己挑。

## 2. 拿到创建需求要的字段

调 `canvas_operation_contract`（`domain=requirement`，`action=create`），按返回的 schema 确定必填和可选字段。分类、流程这类字段有固定取值的，用 contract 里说明的查询 action 取候选值，不要编造。

## 3. 补齐信息

从用户的话里提取标题、需求描述、截止时间、参考资料等。缺少必填项时一次性问清楚，不要逐条追问。

## 4. 确认后再创建

创建前用几行列出：项目、标题、关键要求、截止时间、其他会提交的字段，问用户"确认创建吗？"。用户同意后再调 `canvas_requirement`（`action=create`）。

## 5. 回报结果

告诉用户需求已创建：标题、所属项目、需求编号或链接，以及接下来会由谁处理（如果接口返回了）。创建失败时，原样转述错误原因并说明需要补什么，不要换个参数反复重试。
